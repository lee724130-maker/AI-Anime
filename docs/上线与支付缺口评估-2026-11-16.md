## 一、结论：roadmap 的「真实支付对接未做」已过时

支付宝支付在**代码层面已完整实现并通过配置就绪**，不再是待开发项：

| 回调地址 | ✅ 生产 notify/return URL 已配置 | `.env:36-37`（anime.leesystem.xyz） |

**唯一缺口 = 三个密钥**（`ALIPAY_APP_ID` / `ALIPAY_PRIVATE_KEY` / `ALIPAY_PUBLIC_KEY`）。
`.env` 里只有 gateway/notify/return，没有这三个 key → SDK 启动时走「未配置」warn 分支，`isConfigured()` 返回 false，支付入口不可用。

## 二、必须老板本人操作的步骤（我无权也不应代做）

1. **申请支付宝开放平台商户资质**：营业执照 + 开发者审核（个人主体无法开通电脑网站支付）。
2. **创建应用 + 开通「电脑网站支付」能力**，拿到 APPID。
3. **生成 RSA2 密钥对**，上传应用公钥，拿到支付宝公钥。
4. **把三个密钥写入生产环境**：`production .env` 与 `.env.local`（注意 `.env.local` 优先，两个文件都要写）。
5. **配置回调地址白名单**：`https://anime.leesystem.xyz/api/payment/alipay/notify`。
6. **沙箱联调**：先用支付宝沙箱跑通「下单→支付→回调→积分到账」再切生产。

> 密钥绝不能进 git / 文档 / 日志。本项目约定 key 存 `system_configs` 或 `.env*`（不跟踪）。
