## 二、官方文档核实（用户提供三份）

| 模型 | 参数格式 | 结论 |
|---|---|---|
| `agnes-image-2.5-flash` | `size` 档位 `1K/2K/3K/4K` + `ratio`（8 种） | ✅ 采用 |
| `agnes-image-2.1-flash` | 与 2.5 完全一致 | ✅ 采用 |
| `agnes-image-2.0-flash` | 精确尺寸 `1024x768` 等、无 `ratio` | ❌ 用户决定不用 |

共同要点：`extra_body.image` 支持图生图/多图合成；`response_format` 必须放在 `extra_body` 内；不需要 `tags:["img2img"]`；体验价 $0。

**端点实测**：`api.agnes-ai.cn`（项目中国区 key）有 2.1/2.5 且可用；官方 `apihub.agnes-ai.com` 虽列 2.0，但中国区 key 生成返回 `401 Invalid token`，而 2.0 在中国区又返回 `404 当前分组不支持模型` —— 这是放弃 2.0 的客观依据，也省掉了双端点/双密钥的复杂度。

## 三、改动清单

### 1. `backend/src/utils/ai-service.util.ts`

- `AGNES_IMAGE_MODELS = ['agnes-image-2.5-flash','agnes-image-2.1-flash']` + `AgnesImageModel` 类型
- 单一端点常量 `AGNES_IMAGE_ENDPOINT = 'https://api.agnes-ai.cn/v1/images/generations'`
- `generateImage()`：`provider` 强制 `'agnes'`（忽略 DB `image_provider`）；白名单校验（非白名单 model 忽略并回落 2.5）；写实优先通义分支加 `provider !== 'agnes'` 停用；新增统一入口 `if (provider === 'agnes') → generateImageWithAgnes`，其后所有其他厂商 fallback 不再执行
- `generateImageWithAgnes()`：只用两款白名单；请求体统一 `{ model, prompt, size, ratio, n:1, extra_body:{response_format:'url'} }`；未指定 model 时 2.5 → 2.1 自动回退
- 已删除：`AGNES_HUB_ENDPOINT`、`agnes_apihub_api_key` 读取、`pickAgnesExactSize()`、2.0 精确尺寸分支

### 2. `backend/src/modules/generate/generate.service.ts`

- `textToImage()` model 校验改白名单（非 2.1/2.5 直接 400），不再查 `model_configs.findActive('image')`
- `model_name` 回填实际模型（未指定记 2.5），修复历史任务模型名为空

### 3. `frontend/src/pages/Generate/index.tsx`

- `Form.useWatch('model', formTextToImage)` 动态更新 Tag
- **「生图模型」`Select` 下拉框**，与风格 / 数量 / 强度同处一个 `<Space>` 一排：
  - `Agnes Image 2.5 Flash（推荐）` → `agnes-image-2.5-flash`
  - `Agnes Image 2.1 Flash` → `agnes-image-2.1-flash`
  - 默认 2.5
- 原先的 Radio.Button 按钮组与 2.0 Tooltip 已移除

### 4. DB

- `model_configs`：active 生图模型恰好 **2.5 / 2.1** 两条；2.0 置 inactive；其他厂商 active 置 inactive
- `image_provider = agnes`（代码已忽略，仅作记录）
- 已删除 `system_configs.agnes_apihub_api_key` 配置项

### 仍未接上的两处（诚实说明）

1. **图生图 / 多图合成**：页面「多图合并」仍是「功能开发中」占位，controller 是假端点，`ImageGenerationOptions` 无参考图字段，`extra_body.image` 未使用。虽然两款模型官方都支持，但**项目侧没有这条通路**（见 `docs/generate页面接线审查-2026-11-05.md` §四）。
2. **页面真实提交未代跑**：会扣平台积分（1K = 5 分/张），按约定由用户自测；已验证的是编译、服务、DB、端点直连出图。

视频模型不在本次改动范围。

## 五、怎么用
