# 漫画工作室 · 角色设定本「应用大资产」i2i 改造（2026-11-11）

## 1. 背景与需求

原设定本每块只能手填 `/static/` 素材图路径（0 积分、不走生图）。用户希望：
- 不手填路径，而是把开源图（人脸 / 服装 / 姿势 / 造型）**保存到大资产库**；
- 在设定本里点「应用大资产」→ 弹出挑选器选图；
- 选中的图作为**参考图（i2i）**生成该块（三视图 / 表情组 / 局部特写等）；
- 设定本块从 4 块扩到 **7 块**：新增 **人物服装 / 姿势 / 造型**。

已与用户确认三决策：每块独立参考图 / 仅选已存大资产库的图 / i2i 用对应参考图。

## 2. 后端改动

| 文件 | 改动 |
|---|---|
| `comic-studio.service.ts` | ① `importOpenImage` 导入即建 `GlobalAsset`（tag=face/costume/pose/styling，`source_type=open_gallery`，按 image_url 幂等去重）；② 块模型加 `reference_image`/`reference_asset_id`；③ 新端点 `setBlockReference`（`PUT /sheets/block-reference`，支持 `assetId`/`referenceImage`/`clear`）；④ `blockPrompt` 适配 i2i（姿势块禁止重新引入姿势约束，符合 R7）；⑤ `SHEET_BLOCKS` 4→7 块；⑥ `assembleSheet` 改动态网格（ffmpeg xstack 支持任意 N 块，不足补纯色，输出约 1536×1536）；⑦ `listCharacters` 排除 `open_gallery` 资产避免污染角色选择器 |
| `comic-studio.controller.ts` | 新增 `PUT /api/comic-studio/:id/sheets/block-reference` |
| `generate.service.ts` | `createSheetBlockTask` 放开 `images` 入参（传则 i2i，不传纯 t2i） |
| `OpenGallery` 前端 | 导入调用补传 `kind`/`title`，让大资产 tag 有意义 |

> 说明：`generateCharacterSheet` 现在对每个块把 `images: [reference_image]` 传给 `createSheetBlockTask`，已绑定参考图的块自动走 i2i；未绑定的块仍纯 t2i。设定本块**不计入 `total_credits`**（与剧情页口径不对称，已知，未擅自改）。

## 3. 前端改动

- 新增 `BlockAssetPicker` 弹窗：两个 Tab——「我的资产库」（`GET /api/global-assets?tag=<类别>` 过滤）+「开源图鉴」（一键导入并应用）。
- 设定本每块 UI：参考图缩略图 +「应用大资产」「移除」按钮；删除原手填 `/static/` 输入框。
- `BLOCK_LABELS` 补 人物服装/姿势/造型；`BLOCK_REF_TAG` 映射块→参考类别（portrait/three_view/expressions/details→face，costume→costume，pose→pose，styling→styling）。

## 4. 用户操作流

1. 漫画工作室 → 角色设定本 → 选人物某块（如「正面头像」）。
2. 点「应用大资产」→ 弹窗按块类别列出大资产库图（或去开源图鉴导入）。
3. 选图 → 后端 `block-reference` 绑定该块（状态置 pending，旧图作废）。
4. 点「重生成未完成块」→ 该块以所选参考图 i2i 生成；全部 7 块完成后自动拼版。
5. 确认无误 → 锁定设定本（后续每页生图以它为身份基准）。

## 5. 自测与成本（A12 报备）

- i2i 与 t2i 同价：1K = 5 分/张。1 人物 × 7 块 ≈ **35 分（1K）**。
- Agnes 账号级 rpm 硬上限（≈1 张/4~5 分钟，无实名提 rpm 功能）→ 7 块须分批、约 30+ 分钟跑完，属预期节奏。
- 最小自测：新建项目 → 识别 1 人 → 生成人设 → 给 1~2 块「应用大资产」挑图 → 重生成，肉眼判 i2i 是否采纳参考图；其余块先 t2i，确认 7 格拼版正常。
