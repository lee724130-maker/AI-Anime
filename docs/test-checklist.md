# Part 1: 测试流程

## 准备工作

### 开发前必读
- **每次进行开发修改前，先检查 `项目测试流程.md`、`后续开发清单.md`、`所有可用模型.md`、`CHANGELOG.md` 及相关上下文，理清前因后果后再动手**
- **每次测试前先检查**前后端是否已在运行，不要重复启动
- **不要每次都开新的后端进程顶掉旧的**
- **后端进程关闭后需手动重启，不要自动启动**

### 进程管理
```powershell
# 查看端口占用
netstat -ano | Select-String "3000|5173"

# 查看 Node 进程及其启动命令
wmic process where "name='node.exe'" get processid,commandline /format:list

# 启动后端（在 AI-Anime 目录下）
npm --prefix "C:\Users\Administrator\Desktop\AI-Anime\backend" run start:dev

# 启动前端
npm --prefix "C:\Users\Administrator\Desktop\AI-Anime\frontend" run dev

# 停止（找 PID）
netstat -ano | Select-String "3000"
Stop-Process -Id <PID> -Force
```
