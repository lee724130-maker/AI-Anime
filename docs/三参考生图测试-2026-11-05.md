## 五、与历史实验的冲突（重要）

| 历史结论 | 证据 | 本次 |

| 关节人偶线稿输入 → `content_policy_violation` | 11-03 A8 探针 3/3（P019/P047/custom_pose_female_003） | ❌ 本次 200 且线稿姿势生效 |

| i2i 下文字姿势压不住参考图姿态 | R4（姿势块前置 + FORBIDDEN 仍失败） | 本次用极简提示词，未堆姿势文字 |

**三个同时变化的变量（未做单变量对照，不能断言因果）**：
1. 人物参考 2D 插画 → **真人照片**（最可疑）
2. 提示词长篇（画风/姿势/服装/负面清单）→ **极简三句**
3. 线稿条目不同（`full_sexy_P001` vs `P019/P047/custom_pose_female_003`）

**结论修正**：旧表述「线稿必被拦 / 三图必失败」应改为「**特定组合下会失败，不是绝对**」。当前已验证可用组合 = 真人人物照 + 无人服装图 + 该线稿 + 极简提示词。
