**核心发现（与 11-05 项目实验结论一致，本次再次复现）**：
Agnes 的 i2i **不把参考图当身份/骨骼约束，只当风格与构图提示**。三轮 i2i 里：
- 明确写「no thumbs-up / no bystanders / no crowd」，V2 依旧把竖大拇指和观众席完整搬回来；
- 明确写「keep EXACT real face / do NOT beautify / two DIFFERENT individuals」，V3 用纯脸部裁切后，两张脸仍被统一美化成同款偶像脸；
- 长负面清单不但无效，还会挤掉构图细节（V2 画面反而比 V1 退步）。

→ **要真人本人，别指望模型换脸，用排版层直接上真实照片。**

**第二条硬约束（11-05 已验证）**：Agnes 一次渲染多处文字（尤其中文）必崩。所以本流程把画面与文字彻底分离：
- 模型只出「零文字」的对垒画面（`HARD NEGATIVE` 明确禁所有文字/字母/队标字/水印）；
- 赛事标题、队名、选手名、叙事文案全部由 **ffmpeg drawtext 排版层**叠加，中文用 `msyhbd.ttc`，零乱码、可随时改文案不用重新出图。

```
├── txt\                    # 9 段文案（改这里即可换文案，无需重新生图）
└── out\                    # 全部底图与成品海报
```

**复现命令**
```bash
cd /d/AI-Gen-Outputs/poster-work
node poster.cjs T2I-V2 agnes-image-2.5-flash 16:9 1K     # 出底图
node overlay.cjs T2I-V2.png 海报-终版-文生图.png          # 叠文字
# 真人版
node overlay.cjs 真人版-底图.png 海报-真人选手版.png
```

**固定参数**：`agnes-image-2.5-flash` / `16:9` / `1K`（1312×736）/ `n=1` / `extra_body.response_format='url'`；i2i 时 `extra_body.image` 传 2 张 `data:image/jpeg;base64,...`。
**2K 高清版**：同提示词把 `size` 换 `2K` → 2624×1472 / 3032KB，发丝、皮肤、衣料细节明显更细；`overlay.cjs` 已做分辨率自适应（ffprobe 读高，字号与坐标按 `H/736` 缩放），2K 排版与 1K 视觉一致。
限流实测：Agnes 约 4~5 分钟放一张，`429 rate_limit_exceeded`（提示需实名认证提 RPM），脚本自动等 210s 重试，最久一轮 11 分钟。本轮共出图 6 张，全部 ¥0。

## 四、提示词迭代史（这是本轮主要工作）

### V1（两路线同规格，2232 / 2648 字符）
结构：场景 + 左右人物各一段 + 舞台 + HARD NEGATIVE。
- T2I-V1：✅ 单张连续、左右对垒、蓝金分割、中央奖杯、无文字 → 起手就不错，但人物偏小、背景略杂。
- I2I-V1：✅ 构图成立、队服细节对；⚠️ 偏 CG、观众席杂、两张脸同款。

### V2（**精简 + 关键约束前置**，1414 / 1623 字符）
按项目 R8 教训「长强制块会挤掉细节」，把词砍掉 40%，把「ONE continuous photo / exactly TWO people / no text」提到最前，改用 `tight chest-up portraits` 让人脸更大。
- **T2I-V2 ✅ 最佳**：脸更大更突出、背景干净、蓝金能量缝漂亮、质感接近官方赛事海报（判图 8~9/10）。
- I2I-V2 ❌ 退步：禁止过的竖拇指与观众席全回来 → 坐实 i2i 参考图先验压过文字。

### V3（换参考图形态，2127 字符）
思路：只裁**纯脸部**当参考图，让模型没有姿势/背景可抄，并照搬 T2I-V2 已验证的构图描述（`IDENTITY — face close-ups used ONLY to identify`）。
- ❌ 仍失败：人群回来、脸仍被美化成同款、仍偏 CG。
- 结论：不是参考图裁切问题，是**模型 i2i 通道本身不做身份锁定**。

### 最优提示词（T2I-V2 全文，可直接贴进项目 /generate 文生图）
见 `prompts/T2I-V2.txt`。要点：
1. 开头即 `A single continuous photorealistic press photograph, wide 16:9` + `TWO real ... tight chest-up portraits, both faces large and razor sharp`；
2. 左右各一段只写**外貌 + 队服 + 光色**（不写队名字母，避免模型画字）；
3. 舞台只写「暗、虚化、奖杯剪影、顶光、浅景深」；
4. `HARD RULES` 段短而硬：单张连续 / 恰好两人 / 无文字 / 无第三人 / 无 CGI。
5. **绝不写镜头语言**（「先拍…再展示…」会触发三格分镜，见 `docs/图生图-提示词指南.md`）。
