| 表单字段 | 前端 | dto | service | ai-service | 模型请求体 | 判定 |
|---|---|---|---|---|---|---|
| `prompt`（描述） | ✅ 必填 | ✅ | ✅ 短于 15 字会先调 LLM 扩写 | ✅ 按 style 注入/清洗前缀 | ✅ `prompt` | ✅ |
| `style`（动漫/写实） | ✅ 默认 `realistic` | ✅ | ✅ | ✅ `isRealistic` 还决定 provider 优先分支 | 以 prompt 前缀生效，非模型参数 | ✅（但不是模型参数） |
| `num_images`（1/2/4） | ✅ | ✅ | ✅ 拆成正面/背面/左侧/右侧多视角，循环调用 | ✅ `count` | ✅ 每次 `n:1` | ✅ |
| `image_size`（1K/2K/3K/4K） | ✅ 默认 1K | ✅ 白名单校验 | ✅ | ✅ `pickAgnesImageSize()` 强制档位 + 按 1080×1920 推 `ratio:'9:16'` | ⚠️ **只有 Agnes 分支用**；通义分支不使用 | ⚠️ 部分 |

## 三、⚠️ 页面标注与实际模型不符（最重要的坑）

前端 `:492` 硬写：
```tsx
<Tag color="blue">agnes-image-2.5-flash</Tag>
```
但**前端不传 `model`**，后端走 auto 路由。DB `system_configs` 实测：

| 配置 | 值 |
|---|---|
| `image_provider` | `auto` |
| `tongyi_api_key` | **已配置** |
| `agnes_api_key` | 已配置 |
| `sensenova_api_key` / `zai_api_key` | 已配置 |
| `openai_api_key` / `volcengine_api_key` | 未配置 |

`generateImage` auto 分支**第一句**（:332-337）：
```ts
if (isRealistic && tongyiKey) { return await this.generateImageWithTongyi(...); }
```

**因此**：
- 风格 = **写实**（页面默认）→ 走 **通义万相**，**不走 Agnes**；页面上的 `agnes-image-2.5-flash` Tag 是错的
- 风格 = **动漫** → 跳过该分支 → 进入 fallback chain，Agnes 才是首选
- 通义分支不使用 `image_size` 档位，但计费仍按档位倍数扣（1K=1× / 2K=2× / 3K=4× / 4K=8×，基础 5 分/张）
- auto 模式下 `task.model_name` 为空字符串 → **历史记录里也看不出实际用了哪个模型**

要确认实际落点，只能看后端日志里的 `Using 阿里云通义万相 for image generation` / `Using Agnes Image 2.5 Flash ...`。

## 四、图生图（多图合并）：四处全断

| 层 | 位置 | 实际内容 |
|---|---|---|
| 前端 | `frontend/src/pages/Generate/index.tsx:762-767` | `<div>多图合并 / 功能开发中，敬请期待</div>` —— 纯占位，无表单 |
| Controller | `generate.controller.ts:61-64` | `@Post('image-merge') imageMerge() { return { message: '多图合并功能正在开发中，敬请期待' }; }` —— **假端点，不调 service、不接模型** |
| Service | `generate.service.ts` | **完全没有 `imageMerge` 方法** |
| 契约 / 模型 | `ai-service.util.ts:13` / `:839` | 无参考图字段；Agnes 请求体无 `image` |

**结论**：不是「接错了」，是**根本没接**。这与 11-03 A8 偏差报告里记的那条一致（「`generateImageWithAgnes` 请求体根本没有 `image` 字段，docs/agnes-models.md 写的『参考图走 image 数组』是文档有、代码无」）。

**若要在页面上跑通今天的三参考效果，需要补 4 处**（本次未改）：
1. 前端 tab：参考图上传（最多 3 张，≤100KB 压缩）+ 提交 `images: string[]`（URL 或 base64）
2. Controller/Service：`imageMerge` 真实现，dto 加 `images`、`prompt`
3. `ImageGenerationOptions` 加 `referenceImages?: string[]`
4. `generateImageWithAgnes` 的 `extra_body` 加 `image: [...]`（今天 `probe-a-save.cjs` 的请求体就是现成模板）

另需处理：平台积分计费（当前 `estimateCreditCost` 只有 image/video 两类）、内容审核（线稿在特定组合下会被 `content_policy_violation` 拦）。
