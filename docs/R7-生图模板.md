## 五、已验证有效 / 无效（别重复踩）

**有效**
- 姿势零约束声明
- 两图严格分工（IDENTITY ONLY / COSTUME ONLY）
- 画风三段式（丢弃参考画风 + 正面写实描述 + 否定清单）
- 服装逐件枚举
- 短句 `CRITICAL OUTFIT DETAIL`

**无效**（R4/R5/R8 实测）
- 姿势文字约束：姿势块前置、最高优先级、几何锚点、显式 FORBIDDEN —— 肢体动作依然全丢，被明确禁止的「手在额头」仍复现
- 关节人偶线稿作输入图 → `content_policy_violation`（11-03 探针 3/3 稳定复现）
  - ⚠️ **11-05 修正**：此条**不是绝对**。改用「真人人物照 + 无人服装图 + `full_sexy_P001` 线稿 + 极简三句提示词」后，三图请求返回 200 且姿势基本按线稿生效。详见 `明日开工-2026-11-05.md` §11.8。R7 两图基线地位不变；三图是另一条**有条件可用**的链路，尚未做单变量对照。
- 真人照片形态的姿势基准图作第 3 张参考（R5：完全被无视）
- 三图融合（R5：画风服装对、姿势全错）
- 超长强制块（R8：袜子回来了，但白防水台鞋退化、画风变 3D 感）

**根因**：Agnes 的 i2i 模式优先复现参考图自带的姿态，不把文字或额外参考图当骨骼约束。判别实验证明**纯 t2i 能做出精确姿势**（举臂完全笔直），但身份与服装会退化成纯文字 —— **姿势与身份服装在 Agnes 上暂不可兼得**。
